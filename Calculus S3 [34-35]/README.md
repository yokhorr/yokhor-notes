Конспект по матану по Семёновой. В сущности, скорее не конспект, а лекция в текстовом формате. Может использоваться в качестве полноценной замены лекции.

[Проект в Typst](https://typst.app/project/RwjfgazNBMCKVjh42xBLSC).

___

**Поток:** y2025. **Группы:** M3234-M3235.

**Преподаватель:** Семенова Ольга Львовна.

Весь текст конспекта написан на основе актуальных [записей лекций](https://www.youtube.com/playlist?list=PLYA7MCaZ1JJI) с помощью Claude Sonnet: начальная часть — в версии 5.0, остальное — в версии 5.5.
